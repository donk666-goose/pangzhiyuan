字体图标原理

通过 @font-face 加载字体文件，用 CSS 伪元素 ::before 将字符映射为图标字形。

本地方案

CSS 与字体文件均下载至本地 cdn 目录，离线可用，不依赖外部网络。

使用方式

为元素添加类名，如 <i class="fa-solid fa-star">，图标即自动渲染。
