iconfont SVG 下导航

庞智元（23001010304）· SVG symbol 引用 · 全屏固定 · 移动端自适应

实现方式

加载 iconfont.js 得到 SVG symbol 集合注入页面，通过 <svg><use href="#icon-xxx"></use></svg> 引用图标，CSS 设 fill: currentColor 实现随文字变色。

全局 CSS 设计

以 CSS 自定义属性统一管理设计变量，重置全局盒模型与基础样式，导航、卡片、按钮等全部使用 class 选择器，未使用任何 id 选择器。

五个导航项

首页、视频、刷歌、星光、我的，分别对应 icon-shouye-shouye、icon-shipin、icon-yinle、icon-xingguang、icon-denglu。

数字徽章与红点

视频项右上角显示数字徽章 8，刷歌项显示 99+ 溢出样式；星光与我的项右上角显示红色小圆点，提示新消息。
