JavaScript 基础

六种数据类型，
从值开始认识。

传统入门分类包含字符串、数字、布尔值、未定义、空值和对象。点击卡片，查看值、类型判断结果与对应代码。

字符串 String

"你好，JavaScript"

用引号包裹的文本，可以使用单引号、双引号或反引号。

数字 Number

2026

表示整数或小数；传统 Number 类型也包含 NaN 和 Infinity。

布尔值 Boolean

true / false

只有 true 和 false 两个值，常用于条件判断。

未定义 Undefined

undefined

变量已声明但尚未赋值时，其值为 undefined。

空值 Null

null

表示有意设置的“空”值，常用于清除或预留数据。

对象 Object

{ name: "庞智元" }

以属性组织数据；数组和函数也属于对象相关类型。
