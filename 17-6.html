包饺子的异步流程

async / await + Promise.all 控制流程，setTimeout 模拟每一步耗时 | 庞智元

一、流程设计

买原料（6s）→ 取原料（2s）→【和面（4s）∥ 和馅（5s）并行执行，用 Promise.all 等待两者完成】→ 包饺子（3s）→ 吃饺子（2s）。每一步都用 setTimeout 模拟真实耗时。
await 买原料(6000);            // 串行：先买
await 取原料(2000);            // 串行：再取
await Promise.all([和面(4000), 和馅(5000)]);  // 并行：两件事同时做
await 包饺子(3000);            // 等上面都完成才能包
await 吃饺子(2000);            // 最后开吃
点击开始，整个流程约 18 秒（并行节省了时间）
