JavaScript 的两种定时器

setTimeout（延时执行一次）与 setInterval（循环执行） | 庞智元

一、setTimeout：延时后执行一次

设置一个倒计时（默认 5 秒），到 0 时触发一次回调。可以用 clearTimeout 提前取消。
var pzy_timerId = setTimeout(函数, 毫秒数);   // 返回定时器编号
clearTimeout(pzy_timerId);                    // 取消定时器
5.0 s
点击按钮开始，倒计时结束自动隐藏提示

二、setInterval：每隔一段时间循环执行

每 1 秒刷新一次电子时钟，直到点击停止。用 clearInterval 取消循环。
var pzy_clockId = setInterval(函数, 1000);   // 每 1000 毫秒执行一次
clearInterval(pzy_clockId);                  // 停止循环
