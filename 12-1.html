基础用法

:root全局变量

在 :root 伪类中定义变量，整个文档都可以访问。

全局变量--accent
/* 定义 */ :root { --accent: #2563eb; } /* 使用 */ .box { background: var(--accent); }

var()引用变量

通过 var() 函数引用变量的值，可设置 fallback 回退值。

var() 引用
/* 带回退值 */ color: var(--undefined, #333); /* 嵌套使用 */ border-radius: calc(var(--radius) - 2px);

局部作用域覆盖

变量遵循层叠规则，局部定义会覆盖全局同名变量。

局部

局部变量 --local-color

覆盖为 #dc2626

/* 全局定义 */ :root { --accent: #2563eb; } /* 局部覆盖 */ .local { --local-color: #dc2626; background: var(--local-color); }

实战案例

主题切换常用

通过改变量实现深色/浅色主题切换，无需改 CSS。

Light
Dark
/* 切换主题只需改变量 */ [data-theme="dark"] { --paper: #0f172a; --ink: #f1f5f9; --accent: #60a5fa; }

间距系统设计 token

用变量管理间距、字号等设计 token，保持一致性。

--spacing = 1rem
calc(var(--spacing) * 0.5)
:root { --spacing: 1rem; --radius: 8px; } /* 使用 */ .card { padding: var(--spacing); border-radius: var(--radius); }

JS 动态修改交互

JavaScript 可以读取和修改变量，实现动态主题。

JS 控制hue: 220
/* JS 修改变量 */ document.documentElement .style.setProperty( '--accent', '#e11d48' ); /* JS 读取变量 */ getComputedStyle(root) .getPropertyValue('--accent');
